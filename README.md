### 👾 About me

Hey! I like having an idea in the morning and a working thing by the evening.
Then I keep poking at it until it's actually good.

- 🎮 Games and editor tools in **Unity**
- 🤖 Telegram bots for friends, uni and everyday stuff
- 🔔 Small hardware projects, like a school bell running on an ESP32
- 🌐 Odd little websites, like a demob countdown timer
